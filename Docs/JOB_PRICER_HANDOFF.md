# Job pricer — handoff (session of 2026-10-05/06)

Staff quoting calculator for complex multi-garment, multi-technique jobs. Built, verified
and deployed in one session; this doc is the state of play for the next one. The memory
file `project_quote_job_pricer.md` carries the short version.

## Origin

Sean shared Carl's **DSP Supacolour** HTML calculator (DSP's wholesale transfer price
list) asking whether it could be the basis of a quoting tool. Findings: it's a supplier
*cost* sheet, not a sell sheet, and DSP's Supacolour prices are ~40% under our direct
portal (Blocker A4 $4.15 vs $7.18, A3 $6.92 vs $11.81, setup $18.20/$9.10 vs $40/$20).
Sean confirmed DSP is cheaper than us; retail card unchanged; routing through DSP widens
margin. **Open:** whether DSP extends those rates to SC Prints.

Quoting must use *our* pricing: the cost-model workbook
(`~/Library/CloudStorage/GoogleDrive-info@scprints.com.au/My Drive/SC Print/SC-Prints-Cost-Model.xlsx`,
regenerated by `build_cost_model.py`). Its sell cards were already in code
(`scp-dtf-print-pricing`, `scp-screen-print-pricing`, `embroidery-pricing`,
`scp-supacolour-pricing`); its *cost* tables and the trade/BYO/UV DTF cards were not.

## Model (persisted as `quote.metadata.job_pricer`)

```
{ version: 2, saved_at, summary, totals, snapshot, state }
state = { version: 2, tierSlug, designs[], groups[], uvMetres, uvReorder,
          extras[], waivedKeys[], roundUnitTo, discountKind, discountValue }
design = { id, label: "A", repeat, imageUrl }
group  = { id, product: {id,title,handle,thumbnail} | null, supplied,
           rows: [{ id, colour, label, dark, cells: { "<size>": "qty", "": "any-qty" } }],
           positions: [{ id, side, method: print|screen|embroidery, designId, channel, sizeId, colours, stitches, promo }],
           unitOverride }
```
Browser draft: `localStorage["scp:job-pricer:<quoteId|new>"]`. v1 jobs migrate on load.
Product details / print profiles are never persisted — re-fetched by id, handle fallback.

## Pricing rules (as billed = as checkout)

- Garment ladder + full-colour prints tier on the **job-wide** garment quantity (checkout
  aggregates bulk-eligible quantity cart-wide). Garment sell = `garmentMajorWithTier`
  (tier flat price if the customer has a tier *and* a stamped cost, else ladder).
- Screen print tiers **per group**; underbase only on **dark rows**; heavy surcharge from
  `product.metadata.screen_heavy`. Min 25 warns, prices at 25–49.
- Embroidery tiers per group; >12,000 st = "by hand" (priced $0, flagged).
- Supacolour card auto when `metadata.decoration_pricing_class = "supacolour"`; override per position.
- **Every setup once per design**, shared across garments (DSP charges screens per design and
  reclaims them within days — Sean 2026-10-06). `repeat` design: screens $39, transfer $35,
  no digitizing. New position in a group defaults to a *new* letter; duplicating a group keeps letters.
- Cost = workbook constants; garment cost = stamped `cost_price_ex_gst_minor` else
  **estimated** from the 100+ ladder band (`(top − freight/100) / 1.65`, badge "cost est.").
- Margin = sell ÷ 1.1 − cost (ex GST). Job discount is pro-rata on every line's unit price
  (negative lines can't be carted); waived setups list at $0 but keep their cost.

## Quote transfer

One line per colour/size cell (variant id; "Any" cell → whole-product line, size at order
time), structured description `Front: Full-colour print Up to A4 (design A) · Back: Screen
print 1 col + underbase (design B)`, setup lines on `screen-printing-setup-fee` /
`supacolour-transfer-setup-fee` / embroidery setup (matched by title: prod has
`embroidery-logo-setup`), everything else (supplied rows, UV, extras) on `custom-service-line`.
Line ids `jp_r_<row>:<size>` / `jp_x_<key>`; re-save replaces only `jp_` lines. The quote's
`subject` and `total_estimate` are set from the job. `custom-service-line` must stay
published (draft breaks add-to-cart) and in the Internal Services channel.
